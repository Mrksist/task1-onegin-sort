# Евгений Онегин

> А.С. Пушкин так хорошо описал быт и нравы современной ему жизни в поэме "Евгений Онегин", что В. Г. Белинский назвал ее "энциклопедией русской жизни". Но в энциклопедии все должно быть отсортировано по алфавиту; гуманитарий Пушкин этого не знал. Помогите великому поэту сделать из поэмы настоящую энциклопедию, напишите эффективную по времени и памяти программу, которая читает стихотворные строчки из файла, сортирует их (игнорируя знаки препинания) и выводит в другой файл. В случае проблем с русским языком, используйте пьесы Шекспира. Пусть ему тоже мало не покажется.

## Формализация задачи

Требуется построчно прочитать входной файл и отсортировать строки в нем двумя способами: обычным, сравнивая строки с конца, а далее вывести оригинальный текст файла. При этом при сравнении строк любые небуквенные символы (пробелы, знаки препинания, цифры, спецсимволы) должны пропускаться. Основной текст для тестироавния корректности и производительности - текст бессмертной поэмы А. С. Пушкина "Евгений Онегин"

## Общая архитектура

Проект небольшой, содержит лишь один заголовочный файл: `onegin.h`. Данный файл содержит объявления всех собственных типов, структур и функций в программе

Общая архитектура проекта следующая:

```
.
├── include
│   └── onegin.h
├── src
│   ├── comparators.c
│   ├── main.c
│   ├── myqsort.c
│   └── reader.c
```

Решение декомпозировано функционально и файлово для обеспечения большей понятности исходного кода для понимания

## Алгоритм решения

Задача решается в несколько основных логических этапов:

* Чтение всего файла в заранее выделенный буфер 
* Создание массива индексирующих структур для каждой отдельно взятой строки для удобства дальнейшей работы с ними
* Сортировка алгоритмом QuickSort с использованием собственных компараторов и собственной реализации этого алгоритма. Первая сортировка происходит собственно реализованным алгоритмом, вторая сортировка происходит с помощью библиотечной функции `qsort`
* Вывод в выходной файл или `stdout`

## Сборка и запуск

По причине относительной простоты реализации программы, сборка происходит с помощью shell-скриптов `build.sh` и `build-debug.sh`. Второй скрипт собирает отладочную версию программы: санитайзеры, предупреждения компилятора, отладочный вывод. Другой скрипт собирает оптимизированную релизную версию программы

**Опция сборки:** Для меньшего среднего количества действий, выполняемых сортировкой собственной реализации, во время итерации быстрой сортировки средний элемент выбирается случайно. Для детерминированного поведения и выбора среднего элемента из центра рассматриваемой части массива измените в `build.sh` параметр

`-DONEGIN_MYQSORT_SELECT_RANDOM_MIDDLE` 

на

`-DONEGIN_MYQSORT_SELECT_CENTRE_AS_MIDDLE`

Таким образом, центральный элемент будет выбираться из середины части массива. Подробнее про реализацию алгоритма QuickSort можно изучить на Wikipedia: https://en.wikipedia.org/wiki/Quicksort. 

## Использование программы

Все параметры командной строки являются необязательными

```
$ ./onegin [FILE.txt] [-C]
```

* `[FILE.txt]` - файл, из которого будут считаны и отсортированы строки. По умолчанию использован `onegin.txt`, присутствующий в репозитории. Перед запуском файл проверяется на существование
* `-C` (console) - вывод строки в консоль вместо выходного файла `output.txt`
